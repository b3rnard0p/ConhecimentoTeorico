- docker ps: Ver os containers rodando

- docker run <nome da imagem> : Puxar e rodar container

- docker ps -a : Ver todos os containers

- docker image ls : Mostra as imagens baixadas

- docker container rm <nome do container> : Excluir container

- docker image rm <nome da imagem> : Excluir imagem

- docker build -t imagem:tag . : Criar a imagem

- docker run -p 8080:8080 imagem:tag : Subir o container expondo a porta

- docker stop <id do container> : Para um container

- docker login -u usuario : Login com o DockerHub
  - Por o token

- docker build-t usuario/nome da imagem:tag . : Criar a imagem vinculada a o meu usuario

- docker push usuario/nome da imagem:tag : Subir a imagem para o DockerHub

- docker build --plataform linux/amd64 -t usuario/nome da imagem:tag . : Criar imagem mundado a plataforma
